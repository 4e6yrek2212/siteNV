# Шаблон персонального сайта

## Как открыть
1. Распакуйте архив в отдельную папку.
2. Откройте `index.html` двойным щелчком — сайт запустится в браузере.
3. Редактируйте `index.html` в любом текстовом редакторе (например, VS Code или Блокноте).
4. Цвета, отступы и внешний вид редактируются в `style.css`.

## Как добавить фотографии
1. Положите изображения в папку `images`.
2. В `index.html` найдите комментарий «МЕСТО ДЛЯ ...».
3. Замените заглушку на тег, например:
   `<img class="hero-photo" src="images/main-photo.jpg" alt="Описание фотографии">`
4. Укажите точное имя файла и расширение.

## Как добавить документ
1. Положите документ в папку `files`, например `files/presentation.pdf`.
2. Найдите ссылку `href="#"` у нужной карточки и замените на `href="files/presentation.pdf"`.
3. Измените название и описание карточки.

## Как добавить видео
Замените блок с классом `video-placeholder` на:
`<video controls width="100%" src="files/video.mp4"></video>`
и положите видео в папку `files`.

## Важно
- Это статический сайт: формы отправки данных и админ-панели в нём нет.
- Для публикации в интернете нужно загрузить файлы на хостинг.
- Используйте фотографии и отзывы, которые разрешено публиковать.
